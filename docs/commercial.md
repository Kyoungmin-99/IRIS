# 상업용으로 쓸 수 있게 하기 (계획 · 진행표)

목표: 추후 **반드시 상업용으로 출시**할 수 있게 한다(사용자 지시 2026-10-27).

## 두 갈래 + 출시 전 법률 확인 (사용자 결정 2026-10-27)
| 갈래 | 학습 사진 | 용도 |
|---|---|---|
| **연구용**(지금 판) | 모은 사진 **전부** | 점수(목표 95)를 올리는 개발·시험. 계속 한다 |
| **상업용**(함께 준비) | 장부에서 `commercial_ok: true` 인 사진만 + 상업 허락 바탕 모델 | 법률 판단이 '위험'이면 이 판으로 바로 바꿔 출시 |

- **출시 전 법률 전문가 확인 1회**: 연구용 판을 그대로 상업 출시해도 되는지(학습 자료의 NC·ND·출처 미상 사진, 얼굴 사진 동의, 데이터셋 약관).
  '괜찮다' → 연구용 그대로 출시. '위험하다' → 상업용 판으로 바꿔 출시.
- 그래서 **출처 기록을 비공개 장부로 남겨 두는 것**이 어느 쪽 결정이든 필요하다(법률 검토 자료이자 상업용 판의 사진 고르기 기준).
- 상업용 갈래는 같은 학습 도구·같은 시험으로 만든다: 학습 스크립트가 장부를 읽어 `commercial_ok` 사진만 고르는 옵션을 갖추고, 연구용과 점수를 나란히 적는다.
- 법률 검토 때 넘길 것: 이 문서 표, `docs/models.md`(모델별 출처), 장부 요약(갈래별 사진 수 · 라이선스 분포), 바탕 모델 라이선스 목록.

## 원칙
0. **연구용 판은 모은 사진을 전부 활용한다**. 장부에 사진마다 상업 이용 여부만 기록해 두고, 아래 1~4 로 상업용 판을 함께 준비한다.
1. **상업판 학습 사진은 상업 이용이 허락된 것만**: CC0 · 퍼블릭 도메인 · CC BY · CC BY-SA · Pexels/Pixabay 라이선스 · 직접 촬영(촬영자 동의) · 동의서를 받은 인물 사진.
   NC(비상업) · ND(변경금지) · '학술 목적' · 라이선스 미표기 · 출처 미상 사진은 상업판 학습에서 뺀다.
2. **사진마다 권리 기록**: FINDE-photos 비공개 장부 `rights/ledger.jsonl`(사진 sha256 기준: 출처 URL · 작성자 · 라이선스 · 라이선스 URL · 받은 날짜 · 인물 동의 · `commercial_ok`).
   공개 manifest 에는 넣지 않는다(사용자 결정 2026-10-27: 비공개 장부에 따로).
3. **모델마다 학습 자료 목록**: 이 문서 표와 `docs/models.md` 에 어떤 묶음으로 학습했는지 적고, `commercial_ok=true` 인 사진만 쓴 판을 '상업판'으로 따로 만든다.
4. **바탕 모델 · 코드 라이선스**도 상업 허락(Apache-2.0 · MIT · BSD · OpenRAIL-M 등)인지 확인한다.

## 순서 (상업용 갈래 준비 — 연구용 개발과 함께)
0. 자료가 필요 없는 것부터: 얼굴 분할(CelebAMask-HQ)을 MediaPipe 얼굴 점 + 셀피 분할(Apache-2.0)로 대체할 수 있는지 시험 → 되면 상업용 판에서 face-parse 를 뺀다.
1. 장부 규칙을 코덱스에게 전달(요청 게시판 공통 규칙) → 새 수집분부터 `commercial_ok` 기록.
2. 상업 허락 사진이 모이는 대로: 타투 잉크(배경) → 손톱 분할 → 머리카락 매팅 순으로 IRIS 가 상업판 재학습, 지금 판과 같은 시험(손 h68 타투 12장 · 사용자 손 5장 손톱 · 코덱스 손 채점)으로 비교.
3. 얼굴 분할은 MediaPipe 대체를 먼저 시도(모델 없이도 되면 가장 간단).
4. AI 채팅의 스타일 분석 상업판이 나오면 r8 자리에 바꿔 끼움.
5. 모든 칸이 '가능'이 되면 상업판 빌드(비상업 모델이 하나도 안 들어간 빌드)를 따로 만든다.

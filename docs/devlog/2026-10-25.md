새벽에 사용자가 **"코덱스 사진 수집은 멈췄으니 새로 올린 사진으로 전부 학습하고, 필요한 사진은 직접 모으면서 학습하라"** 고 했다.
무엇을 학습할지 물어 **둘 다**(AI 저장소 스타일 분류기 다시 학습 + IRIS 사진 모드 개선을 새 사진으로)로 정했다.
저녁에는 **"네일아트는 아직 손톱 위치를 제대로 못 찾는다"** 는 지적을 받아 내 손톱 찾기를 점검했다.

### 문제와 해결
- 새 사진만으로 그대로 이어 학습하니 새 시험은 34.9 → 53.5% 로 올랐지만 독립 평가 세트가 85.2 → 78.7% 로 떨어졌다. 라벨 하나를 겨냥해 모은 사진이라 드문 라벨만 있어, 평범한 사진을 '컬러 마스카라' · '드레이핑 블러셔' 로 읽었다 → 확신한 답을 기준점으로 함께 넣고, 평가 세트에서 줄지 않고 답 분포가 크게 바뀌지 않는 그룹만 받아들였다.
- 평가 세트 사진이 저장소에 없어 출처 페이지(Flickr · Commons)에서 다시 받았다. Commons 는 요청 제한(429)으로 281장 중 202장까지.
- Codex 리뷰가 기준점 확률에 앱의 온도 보정이 빠졌다고 짚어 고치고 다시 채택했다(받아들인 그룹이 바뀜).
- 아이섀도 오판은 색보정으로 채도가 낮은 사진에서 자연 눈꺼풀의 붉은 기가 줄어 '푸른 컬러 섀도' 로 읽힌 것. 채도로 기준을 낮추거나 양쪽 눈 대칭을 보는 방법은 진짜 연분홍 섀도까지 빼거나 가르지 못해 코드는 바꾸지 않았다.
- 네일은 시험용 '내 손'(`user/hand.png`·`hand.webm`)에 예전 실시간 모드의 파란 가상 손톱이 구워져 있어 진짜 손톱 위치를 잴 수 없었다 → 새 사진 중 실제 손 사진을 '내 사진'으로 써서 점검. 함께 시도한 피부 판정 · 색 상자 변경 넷은 주먹 사진을 망치거나 효과가 없어 되돌렸다. 결과가 칠해지기까지 60초 넘게 걸리는 사진이 있어 시험은 120초 기다림.

### 결정 사항
- 학습 결과는 평가 세트(독립)에서 줄지 않는 그룹만 배포 헤드에 넣는다. 코덱스 사진은 권리 미확인이라 README 권리 표에 적고, 상업 출시 전에는 빼고 다시 학습한다.
- 한국 스타일의 드문 라벨 사진은 자유 라이선스 검색으로는 모이지 않는다 — 코덱스처럼 SNS 쪽에서 모아야 한다.
- 효과를 확인하지 못한 변경은 넣지 않는다(아이섀도 기준 · 네일 피부 판정).

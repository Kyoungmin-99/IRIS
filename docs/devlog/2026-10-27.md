### 문제와 해결
- **배포가 멈춤**: 테스트 사이트를 올리는 GitHub Actions 가 10-26 10:51 UTC 부터 '결제 실패·지출 한도'로 시작조차 안 됨 → 사용자에게 알림(오늘 고친 것들이 아직 사이트에 없음).
- **시험이 중간 그림을 찍음**: batch 가 '6초 조용'에서 찍어, 규칙만 도안이 먼저 구워진 중간 결과를 비교하고 있었음 → 15초, 굽기 기록(bakelog)으로 순서 확인.
- **컨테이너가 거의 매시간 다시 시작**: 학습·시험·합성이 매번 처음부터 → 학습 100 배치마다 저장·`export.py`, 합성·batch·naileval 이어서 하기, `restart_all.sh` 하나로 전부 다시 띄우기. pgrep 이 자기 명령 줄과 겹쳐 셸이 죽거나 대기가 끝나지 않던 것 → PID·/proc 확인.
- **합성 점수 ≠ 실제 점수**: 실제 사진 점수표를 만들고 맨살 팔 28장을 시험 전용으로 따로 둠.

- 모델 교체는 실제 사진 점수로만 판단(합성 검증 IoU 로 판단하지 않음).
- 연구용(사진 전부) · 상업용(장부 `commercial_ok`) 두 갈래, 출시 전 법률 전문가 확인. 앱은 고객 사진만 다루고 수집 사진은 학습·시험 전용.

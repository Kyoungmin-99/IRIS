### 문제와 해결
- **컨테이너가 차례가 끝나면 잠듦**: 배경 학습이 멈춰 있었음 → 차례를 이어 두며 기다리고, 5분마다 저장, `restart_all.sh` 를 켜고 끄는 표시 파일(label · train · tests · collect) 방식으로.
- **선생님 정답의 과잉 · 누락**: 소매 문신 전체를 잉크로 칠함 → 사진의 30% 넘는 상자는 건너뜀, 작은 부분 누락은 '모름'(가중 0).
- **수집 거절**: 커먼즈가 429 로 막음 → 중단. Open Images S3 에 없는 사진(404)을 다시 받느라 시간 낭비 → 바로 원본 Flickr 로(여전히 429 로 느림, 장당 약 1분).
- **calib 0.8 에서 다리털이 어두운 띠로 구워짐** → 0.9.
- **pgrep 이 자기 명령줄을 잡음**: 시작 스크립트가 자기를 죽이거나 건너뜀 → `[x]` 꼴 패턴, 다른 명령과 섞지 않기.

### 결정 사항
- 모델 교체는 실제 사진 점수 + 앱 손·전신 회귀(각 12장)를 모두 통과할 때만.
- 수집은 이용 조건이 공개된 곳만(Pinterest · Instagram 처럼 자동 수집을 막는 곳은 쓰지 않음), 출처·라이선스를 장부에.
- 타투 색 · 네일 색 합성은 그만(AI 채팅 실험 결과).

사용자 지시: '저장소에 사진 커밋은 없을 것, 필요한 사진은 직접 찾아 수집해 학습 계속'. 밤사이 컨테이너가 새것으로 바뀌어
/tmp 의 선생님 정답 2,707장 · 수집 사진 · 학습 저장본 · 파이썬 패키지가 모두 사라졌다. 저장소에 남은 코드와 앱 모델(5단계 판)만으로 다시 세웠다.

### 문제와 해결
- **환경이 통째로 사라짐**: torch 등 패키지도 없어졌고 시스템 pip 이 다른 파이썬(3.13) 것이라 설치가 엉뚱한 곳에 됨 → `python3 -m pip`, 시스템 PIL 이 가려 `--ignore-installed pillow numpy`.
- **Open Images 검증 라벨 파일 이름**: `validation` 이 아니라 `val` (403) → 고침, 없는 파일은 다시 받지 않음.
- **글꼴 받기 거절**: github.com 경로는 세션 권한 밖 → raw.githubusercontent.com 으로.
- **합성만으로 학습 시작**: 실제 사진 조각이 생기기 전에는 기다리도록(합성 점수 ≠ 실제 점수).
- **pgrep 이 자기 명령줄을 잡음**: 프로세스 이름이 든 명령과 섞으면 자기를 죽이거나 실행을 건너뜀 → 실행 명령은 따로.
- **학습이 매시 확인 사이에 멈춤**: 차례가 끝나면 컨테이너가 잠들어 600 배치(약 90분, 정답 붙이기와 CPU 를 나눔)를 다 못 돎.

### 결정 사항
- 앱 모델 교체 기준은 그대로(IoU +0.02 이상, 맨살 팔 오검출이 늘지 않을 것, 손·전신 회귀) → 오늘은 교체 없음.
- 엄격한 calib(0.93)로 오검출을 맞추면 새 저장본 IoU 도 앱과 같아 → 지금 자료로는 앱 수준에서 맴돈다고 판단, 자료(타투 없는 사진·정답)를 더 모으는 쪽으로.

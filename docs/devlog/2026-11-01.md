### 문제와 해결
- **컨테이너가 자주 재시작됨**: 그때 돌던 학습 바퀴가 처음부터 다시 시작된다(180배치 → 0, 120배치에서 멈춤) → 매시 확인 때 파이프라인을 다시 띄우고, 차례를 길게 이어 둔 동안 바퀴를 마침. 근본 해결은 아직 없음.
- **저장본이 앱보다 낮음**: 상자 밖 오검출은 24~27%로 앱(38%)보다 적지만, 실제 타투도 덜 잡아 IoU 가 낮다(잉크를 너무 조심스럽게 잡음). calib 을 낮추면 IoU 는 앱 가까이 오지만 맨살 팔 오검출이 늘어남(0.6: 38장 중 7장).

### 결정 사항
- 앱 모델 교체 없음(기준: IoU +0.02 이상 · 맨살 팔 오검출이 늘지 않을 것 · 손·전신 회귀).
- 같은 방식으로 바퀴만 더 돌려서는 오르기 어렵다고 판단 → 다음은 부정확한 선생님 정답 더 걸러 내기 또는 학습 조각 키우기를 실제 점수로 비교.
